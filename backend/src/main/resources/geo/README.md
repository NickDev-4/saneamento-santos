# Limite municipal de Santos

`santos-municipio.geojson` foi obtido da Malha Municipal do IBGE para o município de Santos (código 3548500), em GeoJSON, com qualidade máxima.

Fonte: https://servicodados.ibge.gov.br/api/v3/malhas/municipios/3548500?formato=application/vnd.geo%2Bjson&qualidade=maxima

Esse limite administrativo é usado como aproximação no ambiente local/demonstração. Configure `SANTOS_SERVICE_AREA_GEOJSON` com o polígono específico da rede atendida quando disponível.
